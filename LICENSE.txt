2. TECHNICAL LIMITATIONS & ACCURACY
===============================================================================

SumScan SastBot uses automated static analysis, Abstract Syntax Tree (AST)
parsing, pattern matching, and optional third-party analysis engines.

AUTOMATED FINDINGS
Static analysis may produce false positives and false negatives. A finding is
an indicator for review, not proof that a vulnerability is exploitable.

MANUAL REVIEW REQUIRED
Findings should be independently validated by a qualified security reviewer or
code auditor before production decisions are made.
