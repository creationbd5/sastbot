# Changelog

## 1.0.0 — First Edition

Initial public edition of SumScan SastBot.

### Application Security
- Built-in multi-language security rule engine.
- Python AST analysis.
- CWE-linked findings, severity, impact and remediation.
- Secure Fix Preview with explicit local-change confirmation and verification re-scan.
- Quality gate, security score and technical-debt estimation.

### Extensible analysis
- Optional Semgrep, Bandit, Trivy, Gitleaks and Tree-sitter integration.
- Engine Manager with status, version, install/test/update workflows.
- DevSecOps configuration checks for CI/CD, containers, Kubernetes and environment files.

### Developer workflow
- Local project scanning.
- GitHub account/repository workflow using GitHub CLI authentication.
- Local-first repository clone and analysis.
- HTML, PDF, SARIF 2.1.0, JSON and CSV reports.
- Persistent local scan history.

### User experience
- Windows and Kali/Linux desktop launchers.
- Animated SUMI security guide with natural/fallback voice support.
- Professional dark cybersecurity UI and SVG branding.
